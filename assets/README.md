# Visual assets

Drop Adobe Firefly / Stitch files here. Vite serves this folder as the site root.

| File | Used as |
| --- | --- |
| `logo.svg` or `logo.png` | Header mark (change `logoSrc` in `config.js` if you rename it) |
| `hero.jpg` (optional) | Not wired by default — add `src="/hero.jpg"` in the header when ready |

Keep filenames stable so you can replace the file without editing layout code.
